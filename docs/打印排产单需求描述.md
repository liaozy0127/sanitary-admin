# 打印排产单功能需求

## 功能概述
在排产单管理页面增加"打印"按钮，点击后生成符合生产车间使用的排产单打印模板，支持浏览器直接打印。

## 配置项

以下字段需要支持配置，从系统配置或环境变量中读取：

| 配置项 | 配置键名 | 默认值 | 说明 |
|--------|----------|--------|------|
| 公司标题 | `PRINT_TITLE_PRODUCTION` | 致恒（致越）金属表面加工厂生产安排表 | 打印文档的主标题 |
| 签名字段1 | `PRINT_SIGNATURE_1_LABEL` | 生产班长 | 第一个签名栏的标签 |
| 签名字段2 | `PRINT_SIGNATURE_2_LABEL` | 仓管 | 第二个签名栏的标签 |
| 签名字段3 | `PRINT_SIGNATURE_3_LABEL` | 签名 | 第三个签名栏的标签 |
| 签名字段4 | `PRINT_SIGNATURE_4_LABEL` | 备注 | 第四个签名栏的标签 |

## 打印模板结构

### 1. 文档标题
- 标题：`{{配置项.公司标题}}`
- 字体：加粗、居中、较大字号

### 2. 表头区域（横向排列）
| 字段 | 说明 | 示例 |
|------|------|------|
| 排产日期 | 日期格式 YYYY-MM-DD | 2026-03-15 |
| 排产单号 | 单据编号 | PC202603-0046 |
| 班别 | 生产班次 | 内/外 |
| 客户 | 客户名称（仅显示第一个客户的名称，或显示"多客户"） | 朋升 |

### 3. 主体表格（表头层级结构）

**一级表头与二级表头对应关系：**

| 一级表头 | 二级表头 | 字段来源 | 宽度建议 | 对齐方式 |
|----------|----------|----------|----------|----------|
| 客户 | - | 客户档案.客户名称 | 12% | 左对齐 |
| 品名规格 | - | 物料档案.品名规格 | 18% | 左对齐 |
| 规格 | - | 物料档案.规格 | 8% | 左对齐 |
| 工艺 | - | 工艺档案.工艺名称 | 12% | 左对齐 |
| 排产数量 | - | 排产单明细.数量 | 8% | 右对齐 |
| 类型 | - | 正常/加急 | 6% | 居中 |
| **完成情况** | 1 | 第一批次完成情况（预留空白） | 5% | 居中 |
| **完成情况** | 2 | 第二批次完成情况（预留空白） | 5% | 居中 |
| **完成情况** | 3 | 第三批次完成情况（预留空白） | 5% | 居中 |
| **完成情况** | ... | 更多批次（根据实际需要） | - | 居中 |
| **完成情况** | 不良 | 不良品数量（预留空白） | 5% | 居中 |
| 备注 | - | 排产单明细.备注 | 10% | 左对齐 |

**表头合并说明：**
- "完成情况"作为一级表头，横向合并多个二级表头（1、2、3...不良）
- 其他列（客户、品名规格、规格、工艺、排产数量、类型、备注）只有一级表头，纵向跨两行
- 二级表头行高较小，一级表头行高较大且加粗

### 4. 底部汇总行
- 合计：所有排产数量的总和（右对齐，加粗）

### 5. 签名区域（底部，根据配置动态显示）
| 签名项 | 说明 |
|--------|------|
| {{配置项.签名字段1}} | 预留空白，待手工签名 |
| {{配置项.签名字段2}} | 预留空白，待手工签名 |
| {{配置项.签名字段3}} | 预留空白，待手工签名 |

**说明**：签名栏数量和标签均可配置，支持 1-5 个签名栏。

## 技术要求

### 前端实现
1. 使用 `window.print()` 或打印预览库（如 vue-print-nb）
2. 打印样式使用 `@media print` 独立控制
3. 表格边框使用蓝色实线（#0000FF 或 #0066CC）
4. 纸张大小：241mm × 120mm（带孔打印纸）
5. 页边距：适配带孔打印纸（上下 10mm，左右 5mm）

### 打印样式要求
```css
@media print {
  /* 隐藏页面导航、按钮等非打印元素 */
  .no-print { display: none; }
  
  /* 表格边框蓝色实线 */
  table { border: 1px solid #0066CC; border-collapse: collapse; }
  td, th { border: 1px solid #0066CC; padding: 4px 8px; }
  
  /* 标题加粗居中 */
  .title { font-weight: bold; text-align: center; font-size: 18px; }
  
  /* 表头字段加粗 */
  th { font-weight: bold; background-color: #f5f5f5; }
  
  /* 合计行加粗 */
  .total { font-weight: bold; }
}
```

### HTML 表格结构示例
```html
<table>
  <thead>
    <!-- 一级表头行 -->
    <tr>
      <th rowspan="2">客户</th>
      <th rowspan="2">品名规格</th>
      <th rowspan="2">规格</th>
      <th rowspan="2">工艺</th>
      <th rowspan="2">排产数量</th>
      <th rowspan="2">类型</th>
      <th colspan="4">完成情况</th>  <!-- 合并4列：1、2、3、不良 -->
      <th rowspan="2">备注</th>
    </tr>
    <!-- 二级表头行 -->
    <tr>
      <th>1</th>
      <th>2</th>
      <th>3</th>
      <th>不良</th>
    </tr>
  </thead>
  <tbody>
    <!-- 数据行 -->
  </tbody>
  <tfoot>
    <tr>
      <td colspan="4">合计</td>
      <td class="total">{{总数量}}</td>
      <td colspan="6"></td>
    </tr>
  </tfoot>
</table>
```

## 交互流程

1. 用户在排产单列表或详情页点击"打印"按钮
2. 弹出打印预览窗口（或新标签页）
3. 用户确认后调用浏览器打印功能
4. 支持选择打印机、打印份数等标准打印选项
