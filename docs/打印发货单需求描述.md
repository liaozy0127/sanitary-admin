# 打印发货单功能需求

## 功能概述
在发货单管理页面增加"打印"按钮，点击后生成符合客户送货使用的发货单打印模板，支持浏览器直接打印。

## 配置项

|--------|----------|--------|------|

| 电话/传真 | `PRINT_COMPANY_PHONE` | 0750-2766036 | 公司电话/传真 |
| 公司地址 | `PRINT_COMPANY_ADDRESS` | 开平市，水口镇，唐良良兴村矮岗山 | 公司详细地址 |
| 联系人1 | `PRINT_CONTACT_1` | 廖总：13536094788 | 第一联系人信息 |
| 联系人2 | `PRINT_CONTACT_2` | 仓管：13672842611 | 第二联系人信息 |

## 技术要求

### 前端实现
1. 使用 `window.print()` 或打印预览库（如 vue-print-nb）
2. 打印样式使用 `@media print` 独立控制
3. 表格边框使用黑色实线（#000000）
4. 纸张大小：241mm × 120mm（带孔打印纸）
5. 页边距：适配带孔打印纸（上下 10mm，左右 5mm）

### 打印样式要求
```css
@media print {
  /* 隐藏页面导航、按钮等非打印元素 */
  .no-print { display: none; }
  
  /* 表格边框黑色实线 */
  table { border: 1px solid #000000; border-collapse: collapse; }
  td, th { border: 1px solid #000000; padding: 4px 8px; }
  
  /* 标题加粗 */
  .title { font-weight: bold; font-size: 18px; }
  
  /* 表头字段加粗 */
  th { font-weight: bold; }
  
  /* 备注竖排 */
  .remark-vertical {
    writing-mode: vertical-rl;
    text-orientation: upright;
  }
  
  /* 合计行加粗 */
  .total { font-weight: bold; }
}
```

## 交互流程

1. 用户在发货单列表或详情页点击"打印"按钮
2. 弹出打印预览窗口（或新标签页）
3. 用户确认后调用浏览器打印功能
4. 支持选择打印机、打印份数等标准打印选项

## 与排产单的区别

| 对比项 | 排产单 | 发货单 |
|--------|--------|--------|
| 用途 | 内部生产安排 | 客户送货凭证 |
| 表头位置 | 标题居中 | 标题右上角 |
| 公司信息 | 无 | 需要显示完整联系方式 |
| 备注位置 | 无 | 表格左侧竖排 |
| 签名对象 | 生产班长、仓管 | 收货单位、仓管 |
| 边框颜色 | 蓝色实线 | 黑色实线 |
