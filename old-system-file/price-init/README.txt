【单价初始化专用目录】

用途
----
本目录存放老系统的历史收货单 Excel 文件，仅用于初始化物料的默认单价。
这些文件中的收货单数据【不会】也【不应该】导入到系统中，否则会导致数据重复。

使用方式
--------
将老系统导出的收货单 .xls 文件放入本目录，可以是多个文件。
然后运行初始化脚本：
    python3 scripts/init_material_price.py

脚本会遍历本目录下所有 .xls 文件，提取（产品名称 + 客户名称 + 单价）组合，
仅更新物料表的 default_price 字段，不会写入收货单相关的任何表。

注意事项
--------
1. 本目录的文件【仅在部署初始化时使用一次】，之后无需保留。
2. 请勿将这些文件通过「收货单导入」功能导入，否则会产生大量重复历史数据。
3. 如果某条物料在系统中匹配不到（按产品名称+客户名称），该条记录会被跳过并记录到日志。
4. 单价 = 0 或异常大值（> 99999）的行会自动跳过。
